# Selected illustrative scripts

The public scripts are compact, portable examples of the principal published
calculations. They are not a dump of the complete historical HPC workflow.

- `ndi_core.py` implements guarded NDI and weighted-summary helpers.
- `plot_public_source_data.py` plots selected monthly summaries from the public
  Zenodo record.
- `plot_global_ndi_banner.py` plots the public Fig. 1a GeoTIFF as a 1400 × 400
  global banner.

No script redistributes provider data or contains credentials, private paths,
manuscript files or editorial correspondence.
