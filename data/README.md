# Data access

Research data are not duplicated in this Git repository.

The numerical source data underlying Figs. 1–5 and Supplementary Data 1–4 are
publicly archived at Zenodo:

<https://doi.org/10.5281/zenodo.21509244>

Raw or provider-controlled IASI/ANNI, HTAP, ERA5, GPM IMERG, SPAM and GSDE
inputs must be obtained from their official providers. Persistent identifiers
and product versions are listed in [`../metadata/data_sources.csv`](../metadata/data_sources.csv).

This separation avoids duplicating large datasets and preserves the original
providers’ licences and version records.
