# Figure source data

The final numerical source data are maintained in the permanent Zenodo record,
not copied into Git:

<https://doi.org/10.5281/zenodo.21509244>

The plotting examples expect the downloaded Zenodo directory to contain the
original archived filenames, including:

- `Figure_1_mean_NDI_2008-2016.tif`
- `Figure_2_monthly_weighted_boxplot_statistics.csv`
- `Figure_3_monthly_climatology_displayed.csv`

See the Zenodo README and data dictionary for every file, variable and unit.
